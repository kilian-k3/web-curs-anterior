# Web del curs anterior

## Descripció

Aquest projecte és una pàgina web desenvolupada durant el curs anterior. Inclou una pàgina d'inici, una galeria, preguntes freqüents, un formulari de registre i diferents apartats amb informació legal.

## Tecnologies utilitzades

- **HTML5:** estructura i contingut de les pàgines web.
- **CSS3:** disseny i estils visuals.
- **JavaScript:** funcionalitats i interaccions.
- **Firebase Hosting:** allotjament i publicació de la web.

## Execució local

1. Descarregar o clonar el repositori de GitHub.
2. Obrir la carpeta del projecte amb Visual Studio Code.
3. Obrir el fitxer `index.html` amb un navegador web.
4. Opcionalment, utilitzar l'extensió Live Server de Visual Studio Code per visualitzar la pàgina en local.
